# Edge Detection and Image Analysis Tool

## Introduction
This project implements different edge detection techniques using Python and OpenCV.

## Algorithms Implemented
1. Roberts Operator
2. Prewitt Operator
3. Sobel Operator
4. Laplacian Operator
5. Canny Edge Detection

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the project:

python main.py

Select an image to view the edge detection results.
