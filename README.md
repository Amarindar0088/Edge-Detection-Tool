# 🖼️ Edge Detection and Image Analysis Tool

**Image Processing and Analysis (IPA) – Mini Project**

A Python-based image processing project that detects edges in an image using five different algorithms and displays their results together for easy comparison.

## ✨ Algorithms Implemented

1. Roberts Operator
2. Prewitt Operator
3. Sobel Operator
4. Laplacian Operator
5. Canny Edge Detection

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- Tkinter

## ▶️ Run the Project

**The easiest way to test the project:**

1. Download the project using the green **Code → Download ZIP** button above.
2. Extract the downloaded ZIP file.
3. Open the extracted project folder in Terminal (Mac) or Command Prompt (Windows).
4. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the following command:

   **Mac:**
   ```bash
   python3 main.py
   ```

   **Windows:**
   ```bash
   python main.py
   ```

6. Select any JPG, JPEG, or PNG image when the file selection window appears.

**That's it!** The program automatically processes the image and displays the original image, grayscale image, and results from all five edge detection algorithms in one window.

The output is also saved as `edge_detection_results.png`.
